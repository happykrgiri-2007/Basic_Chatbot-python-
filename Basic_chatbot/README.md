
# Basic Chatbot Using Python

## About the Project
A simple rule-based chatbot developed using
Python. It interacts with users through text
messages and provides predefined responses.


## Features
- Interactive text-based conversation
- Greeting responses
- Answers basic questions
- Predefined chatbot replies
- Case-insensitive input handling
- Continuous conversation using loops
- Exit command support

## Technologies Used
- Python
- Conditional Statements
- Functions
- While Loop
- Input and Output

## How to Run

python chatbot.py

. Start chatting with the chatbot.
. Type 'bye' to exit.
